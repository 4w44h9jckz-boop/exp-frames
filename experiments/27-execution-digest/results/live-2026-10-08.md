## Inside ethrex

```bash
# from a checkout of lambdaclass/ethrex at c94964843d; EXP is this directory
cp $EXP/ethrex/exp27_execution_digest.rs crates/blockchain/tests/
EXP27_CASES=$EXP/ethrex/cases.txt \
  cargo test -q --release -p ethrex-blockchain --features ethrex-crypto/default \
    --test exp27_execution_digest -- --nocapture
```
