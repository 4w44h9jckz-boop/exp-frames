### Learned

- Reads of named state miss two different things:
  - a write to a slot no entry names;
  - a named value answered by the contract that lies.
- A check that lists writes catches both without mapping slots to resources. Any changed slot
  that `Q` does not list fails.
- $E$ and the account's frame rule each refuse a copy the other admits, so an account taking a
  sponsor needs both.
- Rolled-back body frames still report SUCCESS (experiment 03's observation 2), so a wallet must
  read the transaction's status.
